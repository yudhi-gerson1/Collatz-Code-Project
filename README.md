# 📱 Collatz Code v1.0 (Ultra Pro Max Edition)

Um programa interativo em linha de comando (CLI) desenvolvido em Python para explorar a famosa **Conjectura de Collatz** (também conhecida como o problema 3n + 1).

## 🚀 Recursos
- **Execução Interativa:** Teste múltiplos números em sequência sem fechar o programa.
- **Comando `[acumulo]`:** Uma função dedicada que calcula o somatório de todos os valores gerados na sequência.
- **Resiliência a Erros:** Tratamento de exceções para evitar travamentos caso o usuário digite texto por engano.
- **Menu de Ajuda Integrado:** Dicas de uso e atalhos rápidos de navegação.

## 🛠️ Como Executar
1. Certifique-se de ter o Python instalado na sua máquina.
2. Clone o repositório ou baixe o arquivo `.py`.
3. Execute o script no terminal:
   ```bash
   python collatz_code.py
   ```
